# SIJALAB — A Digital Learning Universe for SIJA Students

> **Discover. Learn. Explore.**  
> Platform web pembelajaran interaktif modern yang dirancang khusus untuk siswa **Sistem Informatika, Jaringan, dan Aplikasi (SIJA)** SMK.

---

## 🌟 Fitur Utama

- **🚀 Interactive Workstation Dashboard**: Live Ping Network Station untuk pengujian latensi ICMP, Daily Quests, streak tracking harian, dan quick-launch toolbelt.
- **📚 Knowledge Center (12 Modul Kurikulum)**: Materi lengkap OSI/TCP-IP, Subnetting, Cisco VLAN & Trunking, Routing OSPF, Linux Server, Bind9 DNS, DHCP, ESP32 SoC, dan Sensor/Aktuator.
- **🔍 Tech Dictionary (29 Perangkat & Sensor)**: Ensiklopedia visual 15 perangkat jaringan dan 14 komponen SIoT & elektronika dengan diagram pinout dan spesifikasi teknis.
- **🧪 Lab Guide & SOP Praktikum**: Panduan langkah kerja terstruktur dengan checklist interaktif real-time, blok sintaks copyable, dan catatan K3 keselamatan kerja.
- **🛠️ Troubleshooting Center**: Knowledge base 8 studi kasus nyata jaringan dan server lengkap dengan gejala, diagnosa, dan langkah verifikasi.
- **🎮 Interactive Challenge & Gaming Hub**:
  1. *Live CLI Terminal Lab* (Debian Linux & Cisco IOS Switch Console interaktif).
  2. *Visual Topology Config Simulator* (Simulasi konfigurasi IP dan uji transmisi paket ping melintasi kabel jaringan).
  3. *Virtual Breadboard & IoT Wiring* (Merakit sirkuit LED, resistor 220Ω, DHT22, dan relay ke ESP32).
  4. *RJ45 Cable Crimping Game* (Merakit 8 warna kawat standar T568B & pengujian LAN Tester).
  5. *Subnetting Speed Challenge* (Teka-teki hitung cepat Network ID dan range host CIDR).
  6. *Technical Crossword* (Teka-Teki Silang kosakata teknis SIJA).
- **🏆 Gamification Center**: Streak calendar, XP points, Level tiers (Novice SysAdmin hingga SIJA Grandmaster), 7 achievement badges, dan dynamic leaderboard.
- **👥 Student Corner**: Ruang kolaborasi berbagi rangkuman belajar, cheat sheet, dan tips ujian praktikum UKK.
- **👤 Profil Siswa**: Portofolio materi dan praktikum tuntas, koleksi bookmark, serta pengeditan profil mandiri.

---

## 🛠️ Teknologi yang Digunakan

- **Frontend**: React 19 + Vite
- **Styling**: Tailwind CSS v4 (Bright, vibrant, clean EdTech aesthetic)
- **Icons**: Lucide React
- **Animations & Effects**: Canvas Confetti, CSS Keyframe Glow & Hover Lifts
- **State & Storage**: React Context API + LocalStorage persistence

## 🚀 Cara Menjalankan Aplikasi

1. **Clone repositori**:
   ```bash
   git clone https://github.com/syifamwlda/SIJALAB.git
   cd SIJALAB
   ```

2. **Instal dependensi**:
   ```bash
   pnpm install
   # atau
   npm install
   ```

3. **Jalankan development server**:
   ```bash
   pnpm run dev
   # atau
   npm run dev
   ```

4. Buka di peramban: `http://localhost:5173`
